# CC0 music

The page's own soundtracks (Settings → Sound → Music: "CC0: March" and "CC0: Retro"). One theme
plays during the game, and the tense one plays during either CO power (see `themeURL` in
`web/sound.js`). Each file is a mono 32 kHz MP3 at 64 kbps of a track released under CC0 1.0
(https://creativecommons.org/publicdomain/zero/1.0/) on OpenGameArt. Each licence was checked on
the track's page on 2026-11-27.

| File | Plays | Track | Author | Source |
|---|---|---|---|---|
| toy-soldiers.mp3 | "CC0: March" | Toy Soldiers | Zane Little | https://opengameart.org/content/toy-soldiers |
| retro-level-1.mp3 | "CC0: Retro" | Level 1, from 5 Chiptunes (Action) / Retro Game Music Pack. The pack's INFO.txt also says CC0 | Juhani Junkala (SubspaceAudio) | https://opengameart.org/content/5-chiptunes-action |
| battle-loop.mp3 | either soundtrack, during a CO power | 8-bit Battle Loop | Wolfgang | https://opengameart.org/content/8-bit-battle-loop |
