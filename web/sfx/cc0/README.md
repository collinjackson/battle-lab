# CC0 sound effects

The page's "CC0" sound effects (Settings → Sound → Sound effects). Each file is a trimmed, mono,
22 kHz MP3 of a sound from [Kenney](https://kenney.nl)'s packs, which are CC0 1.0
(https://creativecommons.org/publicdomain/zero/1.0/), or one made here with ffmpeg. Those are
dedicated to the public domain under CC0 1.0 too. `web/sound.js` (`CC0`) maps the game's sound
names onto these.
